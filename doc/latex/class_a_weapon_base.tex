\doxysubsection{Detailed Description}
Abstract class for all weapons in the Weapon System Plugin. 

Responsibilities\+:
\begin{DoxyItemize}
\item Serve as a base class for different weapon types (melee, magic, throwable).
\item Define common properties and methods for weapon behavior.
\item Facilitate weapon initialization from data assets.
\item Manage weapon mesh and collision settings.
\end{DoxyItemize}

Network\+: available
