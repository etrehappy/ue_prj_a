Spawns a weapon instance in the game world based on the provided gameplay tag.

Current calling sequence:

  • After input, the Character calls UWeaponComponent::EquipWeaponByTag
  • UWeaponComponent::EquipWeaponByTag calls UWeaponFactory::SpawnWeaponByTag
Аргументы
WeaponTagThe gameplay tag identifies the type of weapon that is to be spawned.
Возвращает
A pointer to the spawned weapon instance, or nullptr if spawning failed.
